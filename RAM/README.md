# 8×4 RAM using Verilog

## Overview

This project implements and simulates an **8×4 Random Access Memory (RAM)** using Verilog HDL.

RAM is a memory device that allows data to be both written to and read from memory locations.

This project contains:

* 8 memory locations
* 4-bit data at each location
* 3-bit address input
* Write Enable input
* Clock input
* 4-bit data output

The memory size is:

```text
8 × 4 = 32 bits
```

## RAM Operations

### Write Operation

When `WE = 1` and a rising clock edge occurs, the input data is stored at the selected address.

```text
WE = 1
DATA_IN = data to store
ADDRESS = memory location
```

### Read Operation

When `WE = 0`, the data stored at the selected address appears at `DATA_OUT`.

```text
WE = 0
ADDRESS = memory location
DATA_OUT = stored data
```

## Simulation

This project can be simulated using **Icarus Verilog** and **GTKWave**.

### Step 1: Compile

```bash
iverilog -o ram_sim ram_8x4.v tb_ram_8x4.v
```

### Step 2: Run

```bash
vvp ram_sim
```

The testbench generates:

```text
waveform.vcd
```

### Step 3: View Waveform

```bash
gtkwave waveform.vcd
```

Add the following signals:

```text
CLK
WE
ADDRESS
DATA_IN
DATA_OUT
```

## Expected Operation

### Write

```text
ADDRESS = 000
DATA_IN = 1010
WE = 1
```

The value `1010` is stored at address `000`.

Similarly:

```text
ADDRESS = 001 → DATA_IN = 0101
ADDRESS = 010 → DATA_IN = 1100
ADDRESS = 011 → DATA_IN = 0011
```

### Read

After writing, set:

```text
WE = 0
```

Then select each address.

Expected results:

```text
Address 000 → DATA_OUT = 1010
Address 001 → DATA_OUT = 0101
Address 010 → DATA_OUT = 1100
Address 011 → DATA_OUT = 0011
```
